# Rufai Abdulrahmon — Portfolio

Personal portfolio site for **Rufai Abdulrahmon** — Chief Operating Officer, Marketing Strategist and Tech Operations Lead.

Built with plain **HTML, CSS, and JavaScript** (no build step, no dependencies).

## What's inside
- `index.html` — page structure and content
- `styles.css` — editorial styling with light/dark theme tokens
- `script.js` — theme toggle, mobile menu, scroll reveal
- `portrait.png` — hero portrait image

## Run locally
Just open `index.html` in a browser, or serve it:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Deploy
Drop the folder into any static host (GitHub Pages, Netlify, Vercel). No configuration needed.
